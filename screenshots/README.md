# Screenshot GameHub

Simpan screenshot aplikasi di folder ini. Untuk menampilkannya di README utama, gunakan nama file berikut:

| Nama file | Tampilan yang disarankan |
|---|---|
| `dashboard.png` | Dashboard dengan ringkasan dan status unit |
| `rentals.png` | Daftar unit dan sesi rental |
| `checkout.png` | Ringkasan tagihan dan pilihan pembayaran |
| `reports.png` | Laporan pendapatan dan grafik |

Ambil screenshot dari aplikasi yang sudah dijalankan. Pastikan gambar tidak memuat data pribadi atau informasi sensitif. Format PNG disarankan; JPG juga dapat digunakan.
